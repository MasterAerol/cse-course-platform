# Pronouns and Modifiers Teaching System v1

This canonical teaching system upgrades the existing seventh Verbal Ability topic without changing curriculum order, routes, generators, fixed questions, scoring, assessments, Smart Recovery, or locks.

The twelve authoritative activities retain their audited counts: 12 blocks in the introductory reading and 10 in each remaining activity. Nine reusable text-first VisualTeachingBoard models teach antecedent reference, pronoun case, possession/reflexives, relative-clause roles, adjective/adverb targets, comparison scope, modifier placement, and dangling-actor repair.

The reusable CSE method is `Target → Function → Form → Position → Meaning`. Broad grammar remains owned by Grammar and Correct Usage, while agreement traps remain owned by Subject–Verb Agreement.

The dedicated publisher provides validate-only and capability checks, deterministic comparison, deletion signatures and SHA-256 fingerprinting, fail-closed unknown deletion handling, canonical reconciliation, post-write inspection, idempotency, and `unrelatedTopicsModified: 0`.
